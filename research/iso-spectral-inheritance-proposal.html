Claim discipline

The evidence ladder

The bridge from weight spectra to activation compression has three missing steps. The experiment is designed to falsify the first one cheaply.

Evidence

Base spectra are reusable

In the reported RLVR settings, restoring the base singular values preserves most gains; fixed-spectrum training learns strongly; spectrum-only training barely learns.

Inference

Base activations may share structure

A base-checkpoint activation covariance might define a useful boundary dictionary. ISO does not measure this.

Speculation

A frozen dictionary may reduce mismatch

Stationary decoding might outperform a moving coherent projector when paired with an unbiased fresh residual.

Not supported

The anchor can disappear

A boundary dictionary does not provide dense gradient signs, stale-checkpoint correction, or a check on policy-ratio drift.

What ISO actually fixes

The spectrum is scale, not a codebook

For every selected matrix, ISO keeps the base singular values and optimizes both orthonormal frames. Those frames are precisely the directional information a decoder would need.

ISO parameterization
Wt = Ut Σ0 Vt⊤

Fixed

  • Σ0: base singular values
  • the feasible fixed-spectrum family
  • operator singular-value profile
→

Still changing

  • Ut: output frame
  • Vt: input frame
  • activations, Jacobians and gradients
Online optimizer
GU = GW V Σ0   ·   GV = GW⊤ U Σ0 AdamW or Muon updates U and V separately; polar retractions restore orthonormality.

For an m × n matrix with q = min(m,n), ISO exposes q(m+n) frame elements. Relative to mn dense elements, the ratio is 1 + min(m,n)/max(m,n): square matrices have 2× factor elements before a reconstructed weight or retraction workspace.

The paper reports about 86 seconds of added optimizer time—about 7% of one Qwen3-4B, 8K, A100-80GB end-to-end RL step. That is not a low-bandwidth measurement.

Functional result

Restore Σ0

Keeping RL-trained frames while replacing the learned spectrum with the base spectrum preserves most acquired performance. ISO paper, Fig. 4a, PDF p. 8.

Intervention

Freeze Σ0 during RLVR

Frame-only ISO training learns strongly; the spectrum-only control learns little. Fig. 4b, PDF p. 8.

Necessary freedom

Both U and V move

One-sided or subspace-retaining alternatives leave much more of the endpoint update unexplained; allowing both frames leaves about 2%. Fig. 5, PDF p. 10.

Dimension check. With distinct nonzero singular values, a square 1536 × 1536 fixed-spectrum family still has 1536² − 1536 = 2,357,760 degrees of freedom: 99.935% of the dense matrix count. Fixing the spectrum is a meaningful optimization prior, but not a low-dimensional communication representation.
Paper caveat that matters here. The authors’ own dimension-aware calibration finds no strong extra preference for spectrum-preserving motion beyond high-dimensional geometry. The stronger evidence is functional intervention—not proximity alone. ISO-Optimizer code is also not present in the released local repository as of this review; only the offline merger is released.
Released-code audit

ISO-Merger is an offline frame merger

The 389-line implementation computes FP64 SVDs, retains each selected base matrix’s Σ0, sign-aligns and tangent-projects expert frame changes, masks the trailing 10% of frame-displacement columns, solves clipped Gram weights, polar-retracts both frames, and reconstructs. It is not the online optimizer and it contains no activation codec.

Release limits

Reproducibility is incomplete

Matrix selection is hard-coded to Qwen-style projections plus exact embedding/head names; 1-D tensors use a Euclidean task-vector average; there are no optimizer configs, tests, seeds or benchmark scripts. The output dtype path can retain low-precision rounding, and no final singular-value invariant is checked. The project website is a static result surface, not code.

Shipped fast codec

Rank-77 PowerSGD projector

Sends hQ, reconstructs hQQ⊤, and uses the exact projector adjoint in backward. Anchor-derived Q refreshes are coherent and directional.

Known result

Coherent Q collapses long-horizon

The canonical 200-step run crossed reference KL 1 near step 49 and reached 9.84; reward collapsed around steps 163–171. A frozen pure projector is therefore a risky proposal.

Research incumbent

Fresh PRF exact-k survives 600

Exactly 77 random BF16 coordinates per token stayed stable through 600 steps, but left a roughly 14.4-nat dense/compressed codec wedge. It is recommended by research evidence, not yet the shipped default.

The anchor still corrects weight gradients and staleness. It simply stops refreshing the boundary dictionary. Removing it is a later, separately authorized ablation.

FROST borrows ISO’s inherit once, adapt elsewhere design pattern, not its weight parameterization. The inherited object here is an activation-statistics dictionary Q0, which is an explicit new hypothesis and must beat a frozen random dictionary.

Why not freeze the existing rank-77 projector? It has no residual escape path and permanently deletes the same 1,459 directions. The repository already has evidence that coherent low-rank projection creates directional policy drift. FROST makes the core stationary but gives every omitted coordinate a fresh, unbiased chance to cross the boundary.
Minimal implementation delta

Reuse the experimental FRLR path

Start from the issue-89/93 fresh-residual prototype, set frlr_unbiased=true, rank=49, k=28, and add a base-bootstrap/frozen Q source. Gate off only anchor Q harvesting; do not alter rollouts, AdamW, signed M or W2 RELEX.

Resume requirement

Q0 is part of the checkpoint contract

Persist the exact dictionary artifact, calibration hash, seed and per-boundary checksums. Current PowerSGD reset behavior can re-bootstrap Q after load; that would silently invalidate a “frozen” resumed run and must be blocked.

Exact boundary contract

What crosses—and what never does

Each neighboring stage shares the same immutable dictionary and PRF key schedule. Indices are implicit. Payloads contain only numerical coordinates.

Stage ℓ / encoder

Owns its local weights and Q0ℓ. Splits each hidden token into a 49-D base core and a residual, then selects 28 residual coordinates with a shared counter-based PRF.

c = hQ0
e = h − cQ0⊤
z = e[Jt]
⇄

Stage ℓ+1 / decoder

Reconstructs with the shared dictionary and exact-k residual scatter. The H/k gain makes the reconstruction unbiased over fresh subsets; the receiver computes the next stage normally.

ĥ = cQ0⊤ + (H/k) scatterJt(z) H = 1536, r = 49, k = 28, H/k ≈ 54.86.
EJ[ĥ | h, Q0] = h Because the exact-k subset is uniform and fresh: E[(H/k) scatterJ(e[J])] = e. Q0 and J are detached buffers.
Unbiased means the reconstructed activation only. It does not make downstream logits, losses or parameter gradients unbiased: the network after this boundary is nonlinear. This is a variance-controlled representation experiment, not an unbiased-RL estimator claim.
Forward wire

77 BF16 values / token / boundary

49 core coefficients c + 28 residual values z. The exact-k indices cost zero bytes because both sides derive Jt from sample ID, token position, step, boundary and a shared seed.

Backward wire

77 BF16 cotangents / token / boundary

Let SJ select the k coordinates and g = ∂L/∂ĥ. The receiver sends dc = gQ0 and dz = (H/k)gSJ⊤. The sender applies the exact adjoint:

dh = dc Q0⊤ + dz SJ(I − Q0Q0⊤)

This is not a straight-through estimator and need not equal “compress g with the forward formula.”

L

Stored locally

Stage weights, optimizer state, local activations needed for backward, PRF seed, and the boundary’s Q0 copy on each adjacent stage.

1×

Distributed once

Seven FP32 Q0 dictionaries, basis version, checksum, seed and the fixed calibration provenance. About 2.01 MiB of unique wire data before topology fan-out; about 4.02 MiB resident when both adjacent stages keep a full copy.

↻

Updated during training

Actor weights, AdamW state, replay snapshots, signed-EMA M and RELEX state. Q0 is checksum-locked and never refreshed.

μ

Every microbatch

Forward: c and z. Backward: their cotangents. No dense activations, dense gradients, singular frames, singular values, Q updates or index lists.

Base dictionary construction. Primary: a randomized top-49 eigenspace of each base checkpoint boundary covariance using a fixed MATH calibration batch. Required controls: (1) frozen random Q, and (2) a checkpoint-only “spectral-frame” dictionary formed from the top eigenspace of downstream base-weight Gramians ∑W0⊤W0. The latter is the direct ISO-inspired control; neither is assumed to win.

Direct ISO transplant

No boundary savings

Updating U and V remains local optimizer work and leaves H unchanged. Square factor/state storage is nominally 2× dense, plus Σ0, reconstructed W and polar-SVD workspace. It is excluded from the minimal experiment.

Slow-path accounting is not solved by FROST. The present proxy uses local CPU/GPU transfers and DP collectives, not measured internet sends. A run-90 target-model estimate cites roughly 193 MB for sign(M) and about 3 MB for rank-1 RELEX per anchor fire, while the current implementation can manipulate full FP32 tensors. Topology, sharding and protocol must be specified before those become defensible wire numbers. The existing comm/bytes_* fast metric also counts elements as “bytes” and covers only the gradient-bearing train forward, so the table above is an explicit dtype-aware model that additionally includes backward and old/reference passes.

One hypothesis, staged gates

Hypothesis: a base-checkpoint boundary subspace contains reusable directional information beyond stationarity alone, and an unbiased stochastic tail can preserve safety at the matched 1,232-bit budget.

Stage 0
saved traces first

Offline subspace audit

Using saved base and research traces/checkpoints, compare base-activation Q0, base-weight-Gram QW, adaptive rank-49 Q and frozen random Q. Required assumptions

The idea works only if…

These are testable preconditions, not consequences of ISO. Failure of any first-row assumption is enough to stop the proposal before an anchor-off or lower-budget experiment.

A1 · persistence

Base Q retains useful energy

Across RLVR checkpoints and prompts, Q0 must capture materially more boundary signal or policy-relevant variation than a frozen random frame.

A2 · escape path

The fresh tail controls coherence

Exact-k residual refresh must prevent permanently erased directions from becoming a one-sided policy bias across steps and seven boundaries.

A3 · variance

Unbiased scaling is trainable

The H/k residual gain must not create gradient or logit variance large enough to overwhelm the benefits of a stable core.

A4 · identity

Both sides derive the same Jt

Sample IDs, token positions, step counters, boundary IDs and seeds must survive packing, recompute and resume identically.

A5 · confinement

All compared paths share one codec state

Old, train and reference forwards must use the same Q0 and within-step PRF key; rollout generation remains dense and untouched.

A6 · anchor adequacy

The current slow correction remains valid

Cadence/delay 20, paired replay, W2 and signed M must still stabilize the new codec; FROST does not compensate for a broken slow circuit.

Failure analysis

Reasons FROST may fail

The proposal is deliberately easy to reject. A negative result would rule out a tempting but unjustified reading of ISO before it reshapes the architecture.

HIGH

Spectrum ≠ activation orientation

Σ0 constrains operator scales. Moving U and V, attention, residual additions, RMSNorm and nonlinearities can rotate boundary covariance arbitrarily.

HIGH

Known coherent-erasure failure

A frozen core repeatedly privileges the same directions. The fresh tail reduces—but does not remove—the correlated bias induced by a privileged subspace.

HIGH

Unbiased can still be noisy

H/k ≈ 54.86. Horvitz–Thompson residual scaling is unbiased in expectation but can have severe per-token variance and compound across seven boundaries.

MED

Calibration may be parochial

A MATH calibration batch may encode prompt-length, domain or position structure. Frozen random and weight-only controls are required; out-of-domain checks should follow.

HIGH

Training–inference mismatch remains

Rollouts are generated densely while trainer paths see reconstructed states. A stationary decoder may make the mismatch predictable, but it does not remove it.

MED

No immediate wire win

FROST matches the existing 77-coordinate budget. Eliminating a 3.16 MiB basis refresh every 20 ticks is minor beside token traffic and the slow path.

HIGH

Anchor solves another problem

The anchor supplies dense gradient signs at a corrected checkpoint. Q0 cannot detect stale policy ratios, correct all parameter directions or forecast weight motion.

MED

Current network is simulated

Logical element counters undercount backward, old/reference passes, dtype bytes and some slow collectives. Real topology, retransmission and overlap may change the economics.

Final verdict

ISO is an optimizer clue, not a communication theorem.

The strongest responsible action is a matched-wire frozen-dictionary experiment with an unbiased residual and the dense anchor retained. Anything stronger outruns the evidence.

Supported

Reuse Σ0 for RLVR weights

The ISO interventions support fixed base spectra as a useful weight-optimization prior in the reported settings. Both singular frames must remain adaptable.

Worth testing

Reuse Q0 at boundaries

A base activation dictionary may carry reusable directional structure. FROST is the smallest experiment that isolates this from mere stationarity and coherent low-rank bias.

Do not infer

Remove the slow circuit

No ISO result replaces dense gradient correction, staleness handling or synchronization. Anchor removal requires its own later evidence.

Follow-on long-horizon design

Can the anchor + inherited spectrum prevent collapse?

Conditional yes—but not with the current sign rule alone. The defensible route is a low-bias fast codec, a slow circuit that communicates the dense-minus-compressed gradient error, a synchronized inference-view governor, and a base-spectrum trust envelope. This can bound individual updates and surface divergence early; it cannot guarantee that an uninterrupted run will never stop.

Evidence

The anchor stack is not sufficient

The collapsed 200-step PowerSGD run already used cadence/delay 20, W2 RELEX and all-floating signed EMA. Conversely, PRF exact-k with the same anchor survived 600 steps. This is consistent with persistent codec-direction bias being load-bearing, but protocol differences mean it is not a causal proof.

Evidence

High codec KL can be benign

Run 90 retained validation near 0.66–0.67 through step 600 while its codec-view actor/kl_loss rose toward 0.9. A controller must read an anchor synchronized dense-inference channel, not brake on the codec-view number by itself.

Design claim

Correct the error, then bound the step

The slow circuit should estimate what compression changed, send that residual once with confidence, and let Σ0 define a local update scale. Spectra are a guardrail—not the learning direction.

Important correction to the premise. “The anchor gives the correct direction” is only approximately true. It is delayed, RELEX-projected and batch-dependent. Even a coordinate-wise correct sign does not specify the relative coordinate magnitudes, so the full vector can remain badly rotated inside the same orthant. Reusing one stale sign field for twenty fast ticks can itself become a coherent bias.
1 · Improve the anchor message

Sign is useful—but throws away the error

The current merger keeps the compressed gradient’s magnitude and asks the anchor EMA for one bit of direction.

Current rule
Gcorr = αGfast + (1−α)|Gfast| sign(M),   α = 0.25
  • If signs agree, the coordinate is unchanged.
  • If signs disagree, it flips to the anchor sign at half the fast magnitude.
  • A tiny, noisy or 19-tick-old EMA sign gets the same authority as a stable one.
  • The relative magnitudes still come entirely from the potentially biased fast gradient.
Better target

Send the compression-induced gradient error

On the same paired replay batch, the slow circuit runs a dense backward and a shadow backward through the exact same seeded codec state:

Êa = Gdense,ashadow − Gcodec,ashadow Same weights, samples, PRF keys or Q, objective and replay tick. The difference isolates the codec contribution for the anchor’s shadow objective.

Call this an estimator when the live fast update uses a different PPO normalization or ratio-one surrogate. Stage 0 must test whether it predicts the same-objective dense correction and then the next live fast update; otherwise it remains telemetry. It adds slow compute at anchor cadence, but no fast pipeline-boundary traffic.

Local cost is not wire cost. Ē replaces the incumbent full-sized EMA state, but FP32 error feedback adds one extra model-sized residual: about 6.17 GB for 1,543,714,304 parameters (3.09 GB in BF16). It must be sharded or offloaded and measured before promotion. Persistence stores the previous bit-packed packet plus scales/confidence (about 202 MB), not another full error tensor. The same-codec shadow also adds one extra slow backward per anchor fire—roughly one per 20 fast ticks at the starting cadence. Neither cost appears in the packet total below.

The dominant deployment cost may still be actor synchronization. If the slow circuit does not maintain a persistent replica, a naïve BF16 weight snapshot is about 15.3× larger than the 202 MB SAGE packet. SAGE improves the semantics of the return message; it does not solve fast→slow model synchronization. A real experiment must report both directions, sharding/fan-out and retransmission—not only the attractive bit-packed packet.
Further slow-wire reduction, only after SAGE works: early layers 0–7 were the strongest stored-checkpoint discriminator: the collapsed PowerSGD case showed materially larger early-layer operator/subspace drift than the dense comparator, while healthy PRF allowed useful late-layer adaptation. Restricting the packet to those decoder layers (excluding embeddings and output head) is an approximately 49 MB/fire follow-up. It must be compared with a scope-matched sign-only control so “better message” is not confounded with “fewer corrected layers.”
2 · Reduce mismatch and prevent collapse

Control the dense policy—not the instrument

Use two explicitly different signals: synchronized action-token policy probes at real actor/rollout weight-sync points, and the delayed anchor as a prediction between them. Never present a RELEX-projected checkpoint as the current policy.

Policy channel

probe/kl_infer_sync

At each actor-to-rollout weight refresh, evaluate the same fixed action tokens through the synchronized dense inference path and frozen reference. This is an estimator at exact synchronized weights—not full-distribution KL. Only its re-registered thresholds, never codec-view actor/kl_loss, can authorize a hard brake.

View channel

Inference ↔ codec log-prob error

Track the signed and squared difference between dense and compressed action-token log-probs on the same fixed sentinel and synchronized weights. This isolates instantaneous training–inference mismatch at the probe.

Bias channel

probe/kl_anchor_pred + geometry

Log cos(Êa,Êa−1), dense/codec gradient cosine, ‖Ê‖/‖Gdense‖, projection age/error, and registered early-layer operator/subspace drift. The stale/RELEX anchor is a warning signal with uncertainty; it cannot independently trigger a destructive rollback.

What this does—and does not—repair. SAGE does not make the compressed activation ĥ equal the dense activation h on each pass. It targets the accumulated weight drift caused by a persistent codec-gradient bias and gives the controller a dense view of that drift. The per-pass train–inference wedge remains a codec problem; test FROST or another boundary change separately only after this correction channel is understood.
3 · Use base spectral values safely

Σ0 defines scale—not direction

The base checkpoint can cheaply supply gauge-free trust scales for the seven decoder projection families across 28 layers while both singular frames remain free to learn. Embeddings and the output head are outside this first cap.

Primary spectral use

Dual post-Adam spectral envelope

u2(Δ) = min(‖Δ‖F, √(‖Δ‖1‖Δ‖∞))
γℓ = min(1, ρF,ℓ‖Σ0,ℓ‖F / (‖ΔWℓ*‖F+ε), ρ2,ℓσmax(W0,ℓ) / (u2(ΔWℓ*)+ε))
ΔWℓ = γℓΔWℓ*

Here ‖·‖1 is the induced maximum-column-sum norm and ‖·‖∞ the induced maximum-row-sum norm, making u2 a certified upper bound; use warm-started power iteration as telemetry. Apply the dual cap first to decoder layers 0–7 and the Frobenius leg elsewhere. Frobenius movement alone did not distinguish the healthy and collapsed runs, so it is not the sole guard.

What the bound guarantees

Frobenius and worst singular-value perturbations are bounded

maxi|σi(W+ΔW)−σi(W)| ≤ ‖ΔW‖2 ≤ u2(ΔW) ≤ ρ2σmax(W0)
‖σ(W+ΔW)−σ(W)‖2 ≤ ‖ΔW‖F ≤ ρF‖Σ0‖F Weyl plus Hoffman–Wielandt. These are one-step bounds, not guarantees on cumulative drift, frame rotation or end-to-end Jacobians.

ΔW* must be the complete FP32 proposal after Adam preconditioning, learning rate, decoupled weight decay and SAGE correction, immediately before parameter writeback; audit the realized post-cast delta. Adam moments still reflect the unclipped proposal, so a frequently active cap is a stop/tune signal. No frame is frozen or synchronized.

Store once

Σ0 on slow; two scalars on fast

The slow circuit keeps the base singular values for audit. Each fast stage only needs ‖Σ0,ℓ‖F and σmax(W0,ℓ); both derive from its local base weight, so recurring wire cost is zero. The Frobenius term is ordinary base-weight normalization because ‖Σ0‖F=‖W0‖F; σmax is the specifically spectral control input.

Audit periodically

Separate radial drift from frame motion

At saved checkpoints, log normalized singular drift, early-layer spectral-norm shift and principal angles between clustered near-degenerate subspaces rather than unstable individual vectors. Spectral drift alone never triggers a verdict without policy and capability evidence.

Later canary

Restore Σ0 offline

Only after SAGE passes, evaluate W′=UtΣ0Vt⊤ at a saved checkpoint. If dense policy and validation remain intact, a gentle radial repair becomes a separate ablation—not an automatic training operation.

Why not project every update onto the ISO tangent immediately? Harmful frame rotations can occur while singular values remain fixed; that is exactly what an isospectral constraint permits. A tangent projection could preserve the collapse direction. The first spectral intervention therefore caps update scale and monitors geometry without dictating U or V.
Minimal experiment

Isolate the message, controller, then spectrum

Do not combine SAGE with FROST in the first run. One changes the weight-correction channel; the other changes the boundary representation. A clean result needs one moving part at a time.

message · matched 200

Four-arm message attribution

A0: correction disabled. A: deployed every-tick signed EMA. A′: absolute dense-gradient EMA encoded with SAGE’s identical block quantizer, frozen confidence values, cap, K=20/τ=5 kernel and matched interval dose. B: SAGE error target with that same packet format, fixed LR/cadence and no governor.

All arms execute the extra shadow codec backward—or a cost-matched dummy—and deliver packets at the same registered age. B must beat A0, A and A′; otherwise semantics, dose, compute or staleness remain confounded.
Stage 1B
control · matched 200

Add one mechanism at a time

B: winning SAGE message. C: B + synchronized-inference governor. D: C + dual Σ0 envelope. If D wins, run E: lower-LR incumbent matched to D’s realized total update norm before promotion.

This separately attributes the message, controller and spectral envelope, then tests whether D only shrank the effective step.
Stage 1C
registered stress

Known-bias falsification window

PRF already survives, so its survival cannot prove collapse prevention. After 1A/1B pass, replay the winning controller against one pre-registered biased-codec stress arm spanning the historical PowerSGD failure window, with checkpointed early-stop vetoes.

This is a stress falsification, not a promoted codec and never an automatic launch. Failure to improve the registered drift/reward precursors rejects the prevention claim.

Answer to the three questions

Plausible stability, with a bounded controller—not a promise.

Use the anchor to estimate and transmit compression error, use synchronized inference-view probes to govern actual policy drift, and use Σ0 to limit abnormal update scale. Keep the low-bias codec and retain the anchor.

1 · Sign EMA

Keep the bit efficiency; replace the semantics

Send signed, block-scaled, confidence-gated gradient error with error feedback, not a timeless sign of the absolute dense gradient.

2 · Mismatch / collapse

Close the loop on dense probes

Separate true policy KL from codec-view offset. Brake, repair or roll back before the synchronized-inference trajectory escapes the registered dense-control envelope.

3 · Base spectra

Use Σ0 as a trust ruler

Bound normalized matrix updates and audit drift. Do not transmit or freeze U,V, and do not expect spectra to decode activations.
