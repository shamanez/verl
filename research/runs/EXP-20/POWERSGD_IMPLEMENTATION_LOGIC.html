PowerSGD-Style Activation Compression

A lightweight implementation summary of a low-rank activation codec for pipeline-boundary tensors. This version keeps only the algorithmic logic and omits project-specific files, wiring, and experiment details.

1. Core Idea

At a boundary between two model segments, replace the activation matrix M with its projection onto a shared low-rank orthonormal basis Q.

M shape: (N tokens, H hidden)
Q shape: (H hidden, r rank)
Y = M @ Q
M_hat = Y @ Q.T = M @ Q @ Q.T

Only Y, with shape (N, r), needs to cross the boundary. The basis Q is a shared codebook, so it does not need to be sent with every activation.

Main invariant: if Q.T @ Q = I, then Q @ Q.T is an idempotent projection matrix. The forward pass and backward pass both keep only the same rank-r subspace.

2. Autograd Behavior

The basis Q is treated as a frozen buffer, not a trainable parameter. The activation M remains inside the computation graph. 

q = stop_gradient(Q)
Y = M @ q
M_hat = Y @ q.T

No straight-through estimator is needed. The normal autograd gradient is exactly the projected upstream gradient:

dL/dM = (dL/dM_hat) @ Q @ Q.T

This means the method optimizes through the compressed activation that the next segment actually receives, rather than pretending the dense activation was used.

3. Basis Initialization

Each boundary gets a deterministic starting basis. The basis is drawn from a seeded Gaussian matrix and orthonormalized in fp32. 

seed_boundary = hash(base_seed, boundary_index)
A = randn(H, r, seed=seed_boundary, dtype=fp32)
Q = orthonormalize(A)  # fp32 QR with deterministic sign handling
  • Drawing from a deterministic seed lets both sides reproduce the same initial Q.
  • Orthonormalization is done in fp32 to avoid losing orthogonality.
  • If QR produces a degenerate or non-finite column, replace it with a deterministic random complement and re-orthonormalize.
  • The basis persists across steps; it is warm-started rather than recreated every forward pass.

4. Basis Update

The basis is not updated by gradient descent. It is refreshed with block power iteration on the activation Gram matrix.

During the training forward

Accumulate a sketch off-graph: 

V += M.T @ (M @ Q)   # equals (M.T @ M) @ Q

Accumulating over micro-batches gives:

V = sum_mb M_mb.T @ M_mb @ Q = C_step @ Q

After backward

Orthonormalize the accumulated sketch: 

Q_next = orthonormalize(V)
clear V

This is one block power iteration step:

Q_{t+1} = orth(C_step @ Q_t)

Repeating this drives Q toward the top rank-r right-singular subspace of the boundary activations, which is the best rank-r reconstruction subspace in Frobenius norm.

Important timing rule: the basis must be read-only during the forward/backward work for a step. Update it only after gradients for that step have been computed.

5. Data-Parallel Consensus

If multiple data-parallel ranks see different samples, each rank accumulates a different local sketch:

V_i = C_i @ Q

To keep one shared basis, reduce the raw sketches before QR: 

V_global = all_reduce_sum(V_i)
Q_next = orthonormalize(V_global)

Reducing V is mathematically meaningful because:

sum_i V_i = (sum_i C_i) @ Q
  • Use a sum, not an average; QR is scale-invariant.
  • Reduce the raw sketch, not already-orthonormalized per-rank bases.
  • Run collectives in the same boundary order on every rank.
  • If a rank has no data for a boundary, contribute zeros so collective ordering remains identical.

6. Policy-Gradient Timing

For algorithms that compare an old-policy forward with a train-policy forward, both forwards must use the same frozen basis Q_t for the entire global step.

Old-policy recompute Use Q_t. Do not accumulate the sketch if this forward is under no-gradient mode.
Training forward/backward Use the same Q_t. Accumulate V only from the gradient-bearing training forward.

Updating the basis between these two forwards would change the projection operator and create a spurious importance-ratio shift unrelated to policy parameter changes.

7. Dense Refresh Cadence

Every k steps, optionally disable compression for the full step. 

is_clean_step = clean_cadence > 0 and step % clean_cadence == 0

On a clean step:

  • Run both relevant forwards with dense activations.
  • Do not accumulate V.
  • Do not update Q.
  • Let the optimizer see an exact dense gradient periodically.

This acts as a debiasing refresh for optimizer moments and prevents the low-rank projection from being the only gradient path for long stretches.

8. Numerics

  • Store and orthonormalize Q in fp32.
  • Cast Q to the activation dtype for the projection matmuls if needed.
  • Track Q.T @ Q health; the condition number should stay near 1.
  • Track reconstruction error ||M - M_hat|| / ||M||; this measures whether the learned subspace is useful.
  • If a normalization layer immediately follows the boundary, projection-induced norm shrink is usually absorbed by that normalization. Otherwise, rescaling may need separate validation.

9. One-Step Lifecycle

# Step t
Q = Q_t

old_policy_forward:
    optionally use M_hat = (M @ Q) @ Q.T
    do not update Q
    do not accumulate V if no_grad

training_forward_backward:
    use the same Q_t
    forward sends Y = M @ Q and reconstructs M_hat = Y @ Q.T
    off-graph accumulate V += M.T @ (M @ Q)
    backward sees projected gradient dL/dM = upstream @ Q @ Q.T

optimizer_step:
    update model parameters

post_backward:
    if not clean_step and update_due:
        V = all_reduce_sum(V) if using data parallel consensus
        Q_{t+1} = orthonormalize(V)
        clear V
    else:
        Q_{t+1} = Q_t

10. Minimal Knobs

Knob Meaning
rank r Number of coordinates sent per token at each boundary.
update_cadence How often to run Q = orth(V) on non-clean steps.
clean_cadence How often to run a fully dense debiasing step.
sync_basis Whether to all-reduce raw sketches before QR so all ranks share one basis.
seed Base seed for deterministic per-boundary initialization.
qr_dtype Precision for orthonormalization; fp32 is the practical default.

Bottom Line

The method sends r coordinates per token instead of H, keeps the projection differentiable without a straight-through estimator, learns the shared basis with block power iteration rather than SGD, freezes that basis across paired policy forwards, and optionally inserts dense refresh steps to control optimization bias.
