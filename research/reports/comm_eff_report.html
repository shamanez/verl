0What this is

This is a fork of verl that bolts a communication-efficient training method onto vanilla GRPO. It compresses only the inter-stage (pipeline-boundary) training gradient traffic down to roughly 5% of the dense cost, using a PowerSGD activation codec plus a mandatory stale full-gradient anchor circuit and a per-coordinate merger. Rollouts come from ordinary, uncompressed verl + vLLM — generation is never touched. With the method disabled, training is byte-for-byte identical to upstream verl.

The headline

The stable system — B2, the delayed_ef merger at \(\lambda=1,\ \beta_{\mathrm{anc}}=0\) — reaches GSM8K greedy val@50 ≈ 0.735–0.753 at ~5% of the dense inter-stage gradient communication. That is statistical parity with the same-box dense control (0.7506) and ~96% (near-parity) of the higher same-config dense draw (0.7839). The realistic no-merger floor is 0.6300.

The open research question is whether comm-efficient RL can surpass dense. The converged answer so far is no — not via any anchor-usage lever. The problem is conversion-limited, not generation-limited: the merger reconstructs dense-on-stale, and you cannot beat dense by reweighting, accumulating, perturbing, or de-noising a stale estimate of dense.

Single-draw, seed 0 throughout; greedy mean@1 eval noise is ±0.024. Numbers below are sourced to run artifacts / WandB ids and use the post-#29 paired-replay evidence boundary for anchor-circuit claims; the obsolete 0.7415 "floor" framing is also dropped.

1The stable system

Architecture — two coupled circuits on one process

GRPO's actor update normally runs one dense forward/backward over the rollout-expanded batch, then optimizer.step(). The method splits that update into two circuits sharing the same process, same batch, same optimizer, then merges them per-coordinate before AdamW sees the gradient.

fast (compressed) circuit

Every optimizer tick, the PowerSGD codec compresses each pipeline-boundary decoder-block activation — it projects onto a shared low-rank basis Q and effectively sends only Y = h·Q (77 coords/token vs H=1536). Produces a noisy compressed gradient G_comp. Q is read-only here.

anchor (unmasked) circuit — mandatory

Every cadence ticks, an unmasked GRPO-actor-loss forward/backward runs from a delay_K-stale weight snapshot on an isolated no-hook clone. Its backward yields the clean, DP-reduced, full-coverage stale reference gradient M; its forward recomputes the codec basis Q ← orth(V) and broadcasts it DP-wide. The anchor is the only updater of Q.

The ordering invariant is asserted at runtime: the anchor runs first so its raw gradient feeds the reference before any correction touches the fast grads.

Design intent — the async target

The anchor models a single slow fixed node serving a fast swarm (super-async): it always lags and never leads. So admissible mechanisms use M only as a lagging reference, tolerate variable staleness, and stay cross-rank-identical. The two-circuit structure is mandatory because it is what a real decentralized-PP deployment would use — not an optimization to be removed. This rules out any delay-compensation / lead / extrapolation lever.

The locked substrate. The only axis that varies between arms is the merger. Canonical launcher: examples/grpo_trainer/vast_comm_eff_b2_sota_qwen25_1p5b_grpo_gsm8k.sh (a bare run reproduces B2). Ground truth of any run is its resolved_params.txt.

Communication budget

Measured bytes_ratio ≈ 0.0504 — about 5% of the dense inter-stage gradient communication. Per boundary the fast circuit carries N·r (r=77) instead of N·H (H=1536) values per token; 77/1536 ≈ 0.0501, plus the amortized periodic Q-broadcast.

  • Compressed — the PP boundary, yes. The pipeline-stage-boundary decoder-block activations are the only thing the codec touches.
  • Not compressed — the DP axis, no. On the contrary, sync_basis=true all-reduces the sketch across the DP group so every rank shares one identical codebook Q. Cross-replica / DP gradient compression (Streaming-DiLoCo-style) is an explicitly deferred, out-of-scope milestone, distinct from this PP-boundary activation compression. Rollout traffic is also uncompressed (vLLM is unmasked).

2The big fix — on-policy paired-replay anchor (#29)

issue #29 · merged as PR #16 (d26176b44)

The anchor now computes its stale full-gradient reference M against the policy's own generated batch — the same (batch, θ) the fast circuit saw — via replay_paired_batch=true + snapshot_device=cpu. A weight snapshot taken at the first train_batch tick of a global step is exactly the weights vLLM held when it generated that step's rollouts.

This makes the residual δ = M_rep − G_comp_ring a pure codec error rather than a batch effect, removing the stale-weights × current-batch confound. A bitwise canary fingerprint asserts the loaded weights match the recorded historical weights; a relevance probe (masked mean \(|\log\pi_{\text{loaded}} - \log\pi_{\text{ref}}|\)) sits at the engine-noise floor and stays flat when the pairing is correct.

Every result in this report is post-#29, on this valid-M circuit. The knobs default OFF (replay_paired_batch=false, snapshot_device=gpu) to preserve byte-identity; the B2 launcher turns them on.

3How it works

3.1 · Activation compression — PowerSGD low-rank sketch at the boundary

The codec installs a forward hook on each boundary decoder block holding a single shared, frozen, orthonormal basis Q of shape (H, r), and replaces the block output M (shape (N, H): N packed tokens × H=1536) with its rank-r reconstruction.

projection (the only thing "sent")

\[ Y = MQ \in \mathbb{R}^{N\times r}, \qquad \hat M = YQ^{\top} = (MQ)Q^{\top} \]

Q is detached and M stays in-graph, so autograd yields the exact self-adjoint projector — no straight-through estimator, no custom autograd function:

\[ \frac{\partial L}{\partial M} = \frac{\partial L}{\partial \hat M}\,QQ^{\top} \]

basis update — block power iteration, off-graph

Each compressed forward accumulates a sketch under no_grad, then orthonormalizes. fp32 QR is required — bf16 QR loses orthogonality (\(Q^\top Q\) drifts from \(I\)), degrading the projector and seeding NaNs.

\[ V \mathrel{+}= M^{\top}(MQ) = M^{\top}Y, \qquad Q \leftarrow \mathrm{orth}(V)\ \ (\text{fp32 QR}) \]

sync_basis makes Q a single shared codebook: each rank builds V from its own data shard, so the raw sketches are all-reduced (SUM) across the DP group before orth, and every rank orthonormalizes the same pooled direction — a bit-identical consensus Q. (orth is scale-invariant, so summing rather than averaging is exact.)

\[ V_{\mathrm{global}} = \sum_{\text{ranks}}\sum_{\text{microbatch}} M^{\top}(MQ) \quad (\texttt{sync\_basis: all-reduce SUM before orth}) \]
the load-bearing fact

Because rollouts run uncompressed, the boundary activation second moment MᵀM has a fast-decaying spectrum — the gradient is itself approximately low-rank — so the rank-r projector P = QQᵀ captures most of its energy. The projected step P·g carries the bulk of the reward signal with small bias and low variance. Empirically plain PowerSGD (codec only, no merger) already ties dense. Compression noise is not the limiter of comm-efficient RL — this drives everything in §5.

3.2 · The gradient matrix and the delayed_ef merger

The merger operates on logical 2D matrices, not FSDP shards (the engine summons full tensors). The target set is the 196 decoder 2D matrices = 28 layers × 7, full-coverage (set-equal with the anchor's reference set). Per target it sees three objects:

  • G_comp(t) — the fast compressed gradient this tick (after FSDP DP-mean).
  • G_comp_ring(t−K) — G_comp from K ticks ago, CPU-resident fp32 in a fire-aware ring bounded at ⌊K/cadence⌋+1 = 2 entries at the locked cadence=5/delay_K=5.
  • M_rep(t) — the anchor reference; at β_anc=0 it is exactly the latest fire's paired-replay anchor gradient.

The delayed_ef merger forms the exact K-delayed codec residual — the dense gradient mass the rank-r projection dropped, computed on the identical (batch, weights) pair the anchor just replayed — and re-injects it:

\[ \delta(t) = M_{\mathrm{rep}}(t) - G_{\mathrm{comp,ring}}(t-K), \qquad G_{\mathrm{corr}}(t) = G_{\mathrm{comp}}(t) + \lambda\,\delta,\quad \lambda = 1 \]

δ is refreshed at fire-aligned ticks and held between them; the per-tick injection telescopes toward the delayed dense gradient. Key invariants (unit-tested):

  • Limiting-case identity: λ=0 returns G_comp exactly (same tensor object) ⇒ delayed_ef at λ=0 is plain PowerSGD ⇒ byte-identical to the no-merger floor.
  • Scale contract: M_rep is DP-mean-reduced and G_comp_ring is FSDP-mean under the same loss normalization, so δ is well-scaled with no rescaling in the merger.
  • Cold guards (never a silent grad change): an unwarmed M, a missing/mismatched ring entry, or a logical-shape change ⇒ return G_comp unchanged and count merger_coldM_fallbacks.

3.3 · Anchor gradients — clean stale reference, anchor-owns-Q, β=0

The anchor circuit produces the clean per-target reference M the merger consumes. "Clean" means three runtime-asserted things:

  • Same loss, unmasked. The anchor reuses the GRPO actor loss with the codec disabled, but with importance ratio ≡ 1 (it deliberately ignores old_log_probs, which came from the masked fast path at different weights). With ratio ≡ 1 the per-token loss is \(-A\log\pi\) and its gradient is the clean true gradient at the stale weights.
  • K-stale snapshot, no optimizer step. The anchor forwards from a delay_K-stale snapshot taken off the optimizer's param group; the backward runs on a deep-copied no-hook clone so FSDP's post-backward machinery never fires (asserted to share no id() with the live module).
  • Raw gradient into the reference, before any correction. G_anchor is read raw and fed to the reference before any fast-path corrector runs — the anchor gradient is never itself the input to a correction.

anchor owns Q

The anchor is the only updater of Q: its stale-weight forward harvests boundary activations into V, sets Q ← orth(V), and broadcasts Q (and M) DP-wide (receipt-verified). The fast circuit's basis update is fail-closed. q_basis=act is the only production basis — gradient/adv/tail/hybrid bases anti-converge, because rollouts run uncompressed so the update-energy basis is the wrong one.

β_anc EMA, and why β = 0

\[ M_{\mathrm{anchor}}(t) = \beta_{\mathrm{anc}}\,M_{\mathrm{anchor}}(t-1) + (1-\beta_{\mathrm{anc}})\,G_{\mathrm{anchor}}(t), \qquad \beta_{\mathrm{anc}}=0 \Rightarrow M_{\mathrm{rep}}(t)=G_{\mathrm{anchor}}(t) \]

The design invariant is freshness > variance-reduction. The anchor gradient is a stale / off-policy signal, so an EMA only compounds staleness, and the GRPO clip already caps it (unlike SFT's fixed target). The in-progress EXP-33 sweep (§4) is the direct test: so far β=0 and β=0.25 tie, and no β>0 cell improves on β=0.

the cold-M guard

\[ \lVert M_{\mathrm{anchor}}\rVert \le \epsilon \;\Rightarrow\; G_{\mathrm{corr}} = G_{\mathrm{comp}}\quad(\text{no-op, not zeroed}) \]

Until M warms, every merger returns G_comp unchanged. This is the mechanism by which β=1 (which freezes the EMA at its zero cold-start forever) degenerates exactly to plain PowerSGD — the predicted 0.6300 floor collapse of EXP-33 C4.

5Why anchor-usage levers cap at parity

Because the post-#29 merger reconstructs dense-on-stale. The correction δ = M_rep − G_comp_ring rebuilds the dense gradient from a delayed but matched (batch, weights) pair — and you cannot beat dense by reweighting, accumulating, perturbing, or de-noising a stale estimate of dense. Every post-fix parity result reaches the same ceiling by a different route.

evidence hygiene

The conclusion here rests on EXP-30/31/33, where paired replay makes M_rep a valid lagging reference.

The tournament close

The EXP-31 anchor-usage tournament tested the complete set of ways to use M without changing the codec, Q, batch, or generation — each as B2 + exactly one knob, with an adversarial 8-agent code review returning GO (so the nulls are trustworthy). Against the same-box reference B2_live@25 = 0.7202, all four levers are NULL for surpass:

  • L4 perturbation (σ=0.01 noise on δ): 0.7157 — AdamW rescales isotropic noise away; a regularization control, no anchor-usage path.
  • L2 δ-momentum: μ=0.5 → 0.7089 (parity), μ=0.9 → 0.5701 (regress −0.15) — momentum on a stale reconstruction gives back the lag dense never had.
  • L3 adaptive dose (mean-1 gate, κ=1.0): ratio 0.7119 / cos 0.7134 — modulating the dose of a parity-quality stale signal stays at parity.
  • L1 control-variate: gated out — cov(G_comp, M) ≈ 0, nothing to cancel.

Net: blend does not out-perform sign or EF because all three — and every other anchor-usage lever — hit the same dense-on-stale ceiling. Blend just reaches it cleanly (parity) while sign and EF reach it and then ignite.

6What’s next

converged thesis

Comm-efficient RL is conversion-limited, not generation-limited. The codec/anchor machinery is all train-only and validation is greedy mean@1, so the binding constraint is converting extra training diversity into the greedy mode, not producing it. Manipulating δ cannot supply a signal dense genuinely lacks. To surpass dense, the comm-eff path must inject something dense lacks — which, under the locked surface (forward Q/codec fixed, batch fixed, anchor never leads), lies outside any anchor-usage knob.

The immediate work

  • Finish the EXP-33 β curve (C2 → C3 → C4) to close out the freshness-vs-averaging question and write the verdict over all five cells.

The one compression-specific surpass bet left

On the generation side: raise rollout n and rollout temperature so training diversity relocates the greedy mode — run with a mandatory dense × {T, n} control, otherwise any gain is a generic-RL effect rather than a comm-eff effect. This is a generation-side change outside the EXP-31 mandate; it needs a new plan and an operator decision on the locked surface.

  • Honest prior: <20% for a true greedy mean@1 surpass.
  • Likely outcome: an eval-diversity pass@k edge only, not a greedy-mean win.

The constraint that shapes everything

The deployment target stays fixed: a super-async single slow anchor serving a fast swarm. The anchor always lags and never leads, so admissible mechanisms must use M as a purely lagging reference, tolerate variable staleness, and stay cross-rank-identical. The dense-on-stale ceiling is therefore intrinsic to the realistic setting — not an artifact of the current code.
