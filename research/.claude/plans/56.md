## Hypothesis / deliverable

**This lane does not test a new hypothesis — it INTEGRATES the falsified/confirmed lane hypotheses into one recommendation and answers #56's eight verdict questions with numbers.** The integrated claim to state (and defend against the raw lane numbers):

> The best CURRENT ANCHOR weight-projector is the **fixed #47 damped-linear rule** (single global damping scalar λ≈0.3, anchor spacing Δ=5, tiny state = 1 scalar). On GSM8K it clears the PASS decision rule — op-point median `weight_proj_ratio` **0.9396 < 1**, positive skill, clear `h_star`≈30 global steps, and NO load-bearing block/family fails. Neither fixed second-order (#48) nor the adaptive/self-correcting arms (#49) beat it by the ≥0.01 prefer-simplicity margin, so **prefer-simple selects the fixed rule**. **HOWEVER**, the cross-dataset check (#60, Big-Math EXP-58) shows this winner is **DATASET-SPECIFIC**: on Big-Math it collapses to do-nothing (λ*=0.0, ratio 1.0000) and no method beats `hold_stale`, because consecutive weight-update directions are near-orthogonal (`consec_delta_cos`≈0.15) so there is no persistent trajectory to project along. **Per #56's own decision rule ("a projector that wins on GSM8K but loses on Big-Math should be reported as dataset-specific, not adopted as the ANCHOR default"), the fixed damped-linear projector is NOT adopted as a universal ANCHOR default.** The comm-eff ANCHOR design should therefore gate projection on trajectory coherence and fall back to a shorter refresh cadence / hold-stale where the path is incoherent.

## Verdict questions (must be answered with numbers in verdict.md + report)
1. Which method: **fixed damped-linear** (global scalar) — 2nd-order & adaptive not justified (prefer-simple).
2. Best `Delta_ticks`: **5** (ratio rises monotonically with Δ; Δ5 0.871 < Δ10 0.906 < Δ20 0.940).
3. How far before stale is better: `h_safe` ≈ **30 global steps** on GSM8K (per-step); on Big-Math ≈0 (do-nothing optimal).
4. Cadence-faithful op (Δ=20,h=20): PASS on GSM8K (per-tick ratio 0.940 < 1).
5. #47 primary op (per-step Δ=10,h=10): PASS on GSM8K (0.9396 < 1).
6. Correction state ANCHOR carries: **tiny — 1 global scalar** (fixed λ; the adaptive 1-scalar and 2-param 2nd-order variants add state without clearing the margin).
7. By layer/block/family: a **single global scalar suffices** on GSM8K (no family breaks; #49: helps most embed/bias/v_proj, least q/k_proj — a per-group scalar is optional, not required); on Big-Math no family is helped and **bias is actively harmed** (1.0078).
8. Absolute accuracy + does feedback keep improving: #47 pred_evr **+0.1171**; #49 adaptive marginally higher (+0.1205) but below the 0.01 carry margin; on Big-Math all pred_evr ≤ 0 (do-nothing = 0.0 is best). Feedback (#49) keeps adapting (λ 0.19→0.36) but does not cross the prefer-simple threshold.
