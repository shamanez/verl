## Hypothesis

This is a **collection unit**, not a hypothesis test, so the falsifiable thresholds are *acceptance gates on the captured artifact*. The run is ACCEPTED iff ALL FOUR hold; any one failing is FAILED/STUCK with the named escalation:

1. **FULL weights were saved every step (THE headline gate).** A `full/` dir contains one snapshot per training step — `ls runs/EXP-43/regimeA/weights/full/step_*.pt | wc -l` is in `[78, 80]` — and each snapshot is a loadable state dict of the actual weight tensors, NOT a sketch. The first `full_manifest.jsonl` row reports `n_matrices` ≈ 338 (NOT 196), `dump_dtype="bf16"`, and per-matrix `shape` fields are the true matrix shapes (a `down_proj` is `[1536, 8960]`, never a length-4096 vector). (If no `full/step_*.pt` appear → the observer did not fire → STUCK. If `n_matrices` stays 196 the widened `select_all` did not take effect → STUCK.)
2. **Trajectory length** — the regime-A cell reaches ≥ 80 training steps with no NaN/Inf in any loss field, yielding 80 full-weight snapshots. (Cannot reach 80 steps → STUCK; relaunch once within the iteration budget.)
3. **Dump integrity** — every `full/step_*.pt` loads, contains ≈338 tensors with the expected shapes, and each matrix's stored (bf16) Frobenius norm matches the on-box exact fp32 norm within bf16 rounding (≤ ~1% relative, recorded per-matrix in `full_manifest.jsonl`; checked by `verify_full_weight_dump.py`). (A snapshot that fails to load, has the wrong tensor count/shapes, or whose norms diverge beyond bf16 rounding → escalate: `dump_dtype`→fp32 with a streaming/sparser layout, per `## Compute budget`.)
4. **Dense regime verified codec-OFF** — the `comm_eff` counters are all zero: `powersgd_applications=0`, `anchor_backwards=0`, `spectral_corrections=0` (training path byte-identical to upstream verl).
