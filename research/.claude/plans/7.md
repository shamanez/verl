## Hypothesis

**(a) Formula (unit, codex-verify):** A standalone spectral filter implementing
the paper formula (anchor-EMA → full thin SVD → Tikhonov spectral weights →
two-sided projection → alpha blend) is a **no-op when `alpha=1.0`**
(`G_proj == G_mask` within 1e-6), equals the pure two-sided Tikhonov projection
when `alpha=0`, is **shape-preserving** for representative 2D matrices and a
synthetic anchor-EMA cache, and is deterministic for a fixed seed.

**(b) FSDP application point (two-step GRPO smoke):** Wired into the FSDP actor
path with a **seeded** anchor cache (no live anchor circuit) and applied
**after actor backward and before `optimizer.step()`**, a two-step GRPO smoke
reaches `global_step=2` with `actor/grad_norm` **finite** on every substep, no
NaN/Inf, ≥1 actor param delta step0→step2, **logs which gradient representation
was corrected** (full matrix / `DTensor` / flattened `FlatParameter` slice /
local shard) and **whether correction ran before or after FSDP gradient
reduction**, plus per-target `||G_proj - G_mask|| / ||G_mask||` in `(0, 1]` for
`alpha=0.3`.

**Falsified if** correction makes `actor/grad_norm` non-finite or produces
NaN/Inf (FSDP reduction corruption), if the gradient representation at the
correction point cannot be identified and logged, or if the filter changes
gradient shape.

## Experiment design
```yaml
sweep_grid:
  comm_eff.spectral.alpha: [0.3]        # single operating point; alpha=1.0 and alpha=0 are unit-test invariants, not Vast cells
baselines:
  - dense                                # comm_eff.spectral.enabled=false ⇒ must match dense / EXP-5
ablations:
  - disable_spectral                     # the enabled=false regression check
seed_replicates:  1
fanout_max:       1                      # one Vast cell only — this is a discovery smoke, not a sweep
```

The spectral formula, implemented exactly (per targeted 2D matrix):
```text
M_anchor = beta_anc * M_anchor + (1 - beta_anc) * G_anchor   # anchor-gradient EMA
M_anchor = U S V^T                                           # full thin SVD
d_i      = s_i / (s_i + tau)                                 # Tikhonov spectral weights
X        = U^T G_mask V
G_filt   = U diag(d) X diag(d) V^T                           # two-sided projection
G_proj   = alpha * G_mask + (1 - alpha) * G_filt             # blend; masked grad never discarded
```
Default knobs `alpha=0.3`, `tau=1e-3`, `beta_anc=0.95`. Full thin SVD (low-rank
is a separate later scalability ablation). Target matrices: 2D decoder matrices
that receive gradients; skip norms, biases, embeddings, lm head. The masked
gradient is never discarded — anchor provides geometry, not a replacement.
Ordering (paper): masked fwd/bwd → DP sync → anchor EMA/SVD refresh →
spectral correction → AdamW. Commutativity with FSDP reduction is **tested, not
assumed** — the FSDP application-point discovery is the core deliverable.

## Analyst predicate
- **PASS** iff every box in `## Success criteria` is checked — including a clear
  FSDP gradient-representation finding (container type + correction point
  relative to reduction/clipping logged for ≥1 target matrix).
- **REVISE** if at most `iterations` boxes fail AND the analyst can name a
  concrete `next_actions:` knob/placement change for each — e.g. correction
  before reduction broke grad_norm → move to after reduction; full 2D matrix
  unavailable on one rank → restrict to a single FSDP unit or all-gather one
  matrix for the proof. Per the issue, a minimal unsharded / single-FSDP-unit
  proof for ≥1 target matrix is an acceptable REVISE landing point provided the
  limitation is recorded as a follow-up FSDP-aware design task and the two-step
  smoke still runs without breaking the dense path.
- **STOP** if no safe application point exists under FSDP for any target matrix
  even after the listed fallbacks, OR the hypothesis is falsified (correction
  forces non-finite grad_norm / NaN/Inf / shape change), OR budget exhausted, OR
  `iterations` REVISE cycles consumed. On STOP, open a dedicated FSDP-aware
  spectral-design issue.

## Notes for runner
- `code_change: true` → branch `exp/7-spectral-fsdp-discovery` from
  `origin/vast-ai-workload` (never `main`), push it to origin BEFORE training
  launches so the branch survives a laptop crash. The protect-upstream hook only
  allows writes under `verl/` while on an `exp/*` branch inside the worktree.
- **Instrument first, decide second.** The FSDP gradient-container question is
  genuinely open. Before applying any correction, log `type(p.grad)`,
  `p.grad.shape`, the logical 2D matrix shape, and the FSDP wrapping for each
  target parameter. Decide the application point from those logs, not from the
  simulator's DDP assumptions.
- The simulator applies correction before its manual DP all-reduce and relies on
  linearity + shared anchor cache to commute with dense-mean all-reduce. Under
  FSDP this commutativity is NOT assumed — determine empirically whether
  correction belongs before or after FSDP's gradient reduction and whether the
  full matrix is even available unsharded at that point.
- Use the exact seeded two-step smoke from the issue: `comm_eff.enabled=true`,
  `comm_eff.spectral.enabled=true`, `alpha=0.3`, `tau=0.001`, `beta_anc=0.95`,
  `seed_anchor_cache=true`; masking OFF (combined mask+spectral+anchor is EXP-9);
  `trainer.total_training_steps=2`, `trainer.val_before_train=False`,
  `actor.ppo_epochs=1`; batch 8 / mini 4 / rollout_n 2 / prompt+response 256.
- `seed_anchor_cache=true` populates `M_anchor` with a fixed deterministic PSD
  basis so the filter runs without the (not-yet-built) anchor circuit (EXP-8).
- Reuse EXP-4's `comm_eff` namespace; opt-in, default-off
  (`comm_eff.spectral.enabled=false` ⇒ identical to EXP-5 / dense GRPO).
- Run the `enabled=false` regression cell to confirm the no-op path before
  claiming the disabled-regression box.

## Notes for analyst
- The headline deliverable is the **FSDP gradient-representation finding**, not a
  performance number. Weight the third success box (logged container type +
  correction point relative to reduction/clipping) as the load-bearing claim; a
  finite-grad-norm smoke that fails to identify/log the representation is a
  REVISE, not a PASS.
- The `||G_proj - G_mask|| / ||G_mask||` ratio must be strictly >0 (correction

  means the filter was a silent no-op at `alpha=0.3` → REVISE.
- A single-FSDP-unit / unsharded proof for one target matrix is an acceptable

  FSDP-aware design task; do not score it a clean PASS.
