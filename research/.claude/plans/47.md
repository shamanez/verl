## Hypothesis

The two-anchor **damped-linear** projector

```text
v = theta_t - theta_{t-Delta}
theta_hat_{t+h} = theta_t + lambda * (h / Delta) * v          (0 <= lambda <= 1)
```

with `lambda` chosen **out-of-sample on strictly-earlier windows** from a small fixed
grid, is the correct ANCHOR/FAST linear baseline iff it **strictly improves on naive
linear (lambda=1) at the primary operating point (Delta=20, h=20)** — i.e. GLOBAL median
`weight_proj_ratio < 1.158` (the #45 naive_linear reference at that cell) — AND the lane
returns a decisive, per-group answer to three questions: (1) does OOS-damped also beat
**hold-stale** (median ratio `< 1.0`) at the operating point (i.e. does projection help
at all); (2) `h_safe` — the max horizon `h` where GLOBAL OOS-damped median ratio `< 1.0`
(how far it can safely project); (3) which `layer_idx` / `block_type` / special group, if
any, breaks the global conclusion.

Because damping can only shrink the naive-linear overshoot — the grid nests **hold-stale
at lambda=0** and **naive-linear at lambda=1**, so OOS-damped can never be worse than the
better reference on past data (the OOS gap is the honest cost) — **a ratio `> 1` at long
`h` for ALL lambda is a VALID, decisive negative finding, not a failure.** The lane
PASSES by producing a **correct, schema-verified, machine-readable answer either way**,
rendered in the HTML report — not by damped necessarily winning. It is falsified (STOP)
only if the harness/correctness gates cannot pass or the answer cannot be computed within
the iteration budget.
