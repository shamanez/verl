## Hypothesis

**HEADLINE MUST (deliverable A): given ONLY the Big-Math (EXP-58) fp32 weight trajectory, run one exhaustive projector ablation and NAME the single best way to project a stale ANCHOR's weights forward on this dataset — or PROVE do-nothing is optimal.** Concretely, deliver a single ranked projection-accuracy table over the full base ladder + the #49 self-correcting arms, broken by the six ablation axes below, scored on the EXP-58 trace, and NAME the single best-fitting projection method (highest `pred_evr_pooled`, then lowest `weight_proj_ratio_median`). Absolute accuracy — per-window projection explained-variance (`pred_evr_pooled`, PRIMARY) and per-scalar prediction-R² (`pred_r2_scalar_*`) — is FIRST-CLASS for EVERY arm including `hold_stale` (the do-nothing baseline); `weight_proj_ratio` (vs `hold_stale`) is the comparative verdict metric.

**The falsifiable claim (symmetric):** there exists a projector configuration — some Δ, some order, adaptive or fixed, global or per-family, at some horizon or training phase — that extracts useful signal from the Math trajectory. "Useful" = at the primary op-point (per-tick **Δ=5, h=10**, for comparability with #60) OR at any swept cell, a config beats `hold_stale` by **≥ 0.01 absolute `weight_proj_ratio`** (or strictly extends `h_safe`) WITH positive `pred_evr_pooled` AND a bootstrap/CI (or p10/p90) on the op-point ratio-diff-vs-do-nothing that does NOT straddle 0. If such a config exists → **projectable** (name Δ\*, order, adaptivity, granularity, phase with numbers + CI, and give the Math ANCHOR recommendation). If no config clears the bar → **not-projectable / do-nothing confirmed optimal on Math** (deliver the coherence map that explains WHY, and recommend the ANCHOR use short-refresh / hold-stale, exclude bias, on Math-like regimes). **BOTH outcomes are a valid COMPLETED terminal PASS** (symmetric falsification, mirroring #48/#49/#60). The HEADLINE ranked accuracy table + the named best-fitting method is emitted in EITHER outcome.

**LONGER-HORIZON framing.** The EXP-58 trace spans **1000 global training steps** at 20-step spacing (50 snapshots), so `h` ticks ⇒ `h·20` global steps. The winner's `h_safe`/`h_star` MUST be reported in GLOBAL-STEP terms (×20) in both the verdict and report (e.g. h_safe=10 ticks ⇒ 200 global steps).

**Mechanistic layer (the transferable finding — deliverable C):** a coherence map — `consec_delta_cos` / `dir_cos_median` as a function of Δ, tensor family (`block_type`/`super_block`/`special`), and training phase (early/mid/late) — tied to wherever projection does/does not help. #60 found `consec_delta_cos`≈0.15 on Big-Math (vs 0.86 on GSM8K), global collapses to λ\*=0 everywhere, and **bias is actively harmed at ratio 1.0078**; this lane CONFIRMS/EXTENDS those with the finer grid and checks whether smaller Δ (fresher anchor), a specific tensor family (e.g. embed / an attention projection), or an early training phase is locally projectable where the global full-trajectory scalar fails.

Numeric thresholds: op-point GLOBAL-median `weight_proj_ratio < 1.0` for any "beats do-nothing" claim; ratio-improvement **≥ 0.01** OR strictly-greater `h_safe` for any "config wins" claim; positive `pred_evr_pooled`; CI on the op-point ratio-diff not straddling 0. **Falsification is symmetric** — a clean "not-projectable" negative is a completed PASS, not a failure.
